# 主流海外 VPS 选型速查指南

未购买服务器前，先看清 **IP 属性与回程线路** 差异，再按需直接选型。

## 一、核心类型对比

| 类型 | 本质与特点 | 适合场景 | 代表商家 |
| :--- | :--- | :--- | :--- |
| **双 ISP（俗称伪家宽）** | 机房托管，但 IP 在风控库标注为双 ISP；欺诈分极低、几乎不弹验证、自带 9929/CMIN2 回程；单机性价比最高，但基础带宽偏保守（约 30–50Mbps） | **绝大多数个人/AI 开发者首选**（一台机器兼顾纯净度与线路） | **LisaHost（丽萨主机）** |
| **一线优化线路 IDC** | 纯数据中心 IP，但拥有顶级 CN2 GIA / CMIN2 / 9929 专线；大带宽、晚高峰零抖动；面对极严风控站可能需配双 ISP 落地 | 预算充足、追求极致带宽与稳定性的重度开发 | **DMIT（大妈）**、**BandwagonHOST（搬瓦工）**、**SpartanHost（斯巴达）** |
| **廉价普通 BGP 机房** | 低价纯机房 + 普通国际线路；晚高峰易丢包、IP 滥用严重 | 仅适合练手与备用，**不建议登录重要 AI 账号** | **RackNerd**、**CloudCone**、**Oracle Cloud** |

## 三、实战避坑沉淀：为什么不推荐廉价香港 / 亚太小机？

> [!WARNING]
> **切勿被白天 10ms–30ms 的低延迟迷惑**：实战验证表明，**384MB–512MB 超小内存的廉价香港 / 亚太小鸡**（哪怕标称 CMIN2 / 200M 带宽）存在三大硬伤，**强烈不建议购买或与美西机混用**：
> 1. **晚高峰（20:00–23:30）极不稳定**：廉价小机普遍母鸡超售、共享带宽池拥堵，白天 ping 极低但晚高峰抖动剧烈、频繁丢包甚至断流，体感远差于稳如直线的美西优化线。
> 2. **无法直连海外核心 AI 服务**：香港 IP 普遍被 Claude / OpenAI / Gemini 地理封锁，根本无法承担 AI 开发主力。
> 3. **强行「港美双机分流」徒增维护与风控风险**：为了省几十毫秒日常延迟而维护两台机 + 双订阅 + 复杂分流脚本，不仅配置繁琐，一旦规则漏网还会导致 AI 账号出口 IP 在港美之间跳变触发风控。
>
> **最佳实践**：**一台靠谱的美西原生双 ISP（9929 / CMIN2 / CN2 GIA）单机打天下**。配合纯 TCP `VLESS + Reality + Vision` + `BBR/FQ` + `GEOIP,no-resolve` Fake-IP 秒发，全天候稳定纯净、零分流心智负担。

## 四、选购 4 条硬标准

1. **独立公网 IPv4**（避开 NAT 共享 IPv4）。
2. **系统选 Debian 11 或 Debian 12（x86_64 / amd64）**。
3. **硬件建议**（1–5 人共享足够）：1 核 / **至少 1GB 内存**（避开 384MB–512MB 超售小鸡）/ 10GB+ SSD / 1TB–2TB 月流量。
4. **外层安全组**：若商家自带防火墙，确保放行 `443/tcp`、SSH 端口及面板/订阅端口。
